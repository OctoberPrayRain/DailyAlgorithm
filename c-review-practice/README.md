# C 语言复习配套练习（对应《C语言刷题复习总纲》）

本套练习按总纲核心章节设计，默认使用 `C11`，风格参考 Linux kernel（刷题简化版）。

## 目录说明
- `problems/`：题目说明
- `solutions/`：参考解答（每题一个可独立编译运行的 `.c` 文件）

## 建议刷题顺序
1. `P01` 输入输出与类型
2. `P02` 分支与循环
3. `P03` 函数与递归
4. `P04` 一维数组
5. `P05` 前缀和
6. `P06` 字符串统计
7. `P07` 字符串变换
8. `P08` 指针与数组
9. `P09` 结构体排序
10. `P10` 动态内存
11. `P11` 位运算
12. `P12` 综合（滑动窗口）

## 编译运行示例
```bash
gcc -std=c11 -Wall -Wextra -O2 solutions/P01_sum_two_integers.c -o p01
./p01
```

## 使用建议
- 先看 `problems/` 独立完成。
- 做完后再对照 `solutions/`。
- 在你的总纲文档对应章节补充“我的总结 / 易错点 / 模板”。
