# P01 - 两数求和 测试用例

## 测试用例 1：基础正数相加

**输入**
```
1 2
```

**输出**
```
3
```

**说明**：最基本的正整数加法。

---

## 测试用例 2：包含负数

**输入**
```
-5 3
```

**输出**
```
-2
```

**说明**：测试负数与正数相加的情况。

---

## 测试用例 3：两个零

**输入**
```
0 0
```

**输出**
```
0
```

**说明**：边界情况，两个零相加。

---

## 测试用例 4：大数相加

**输入**
```
1000000000 2000000000
```

**输出**
```
3000000000
```

**说明**：测试超出 `int` 范围的大数运算，需要使用 `long long` 类型。

---

## 测试用例 5：两个负数

**输入**
```
-1000000000 -2000000000
```

**输出**
```
-3000000000
```

**说明**：两个较大负数相加，验证负数溢出处理。
