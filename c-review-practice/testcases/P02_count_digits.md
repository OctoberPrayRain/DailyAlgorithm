# P02 - 统计数字字符个数 测试用例

## 测试用例 1：混合字符

**输入**
```
Hello123World
```

**输出**
```
3
```

**说明**：字符串中包含 3 个数字字符 `1`、`2`、`3`。

---

## 测试用例 2：纯数字字符串

**输入**
```
0123456789
```

**输出**
```
10
```

**说明**：全部为数字字符的情况。

---

## 测试用例 3：无数字字符

**输入**
```
Hello World!
```

**输出**
```
0
```

**说明**：字符串中不含任何数字字符（包含空格和标点）。

---

## 测试用例 4：包含空格和数字

**输入**
```
I have 2 cats and 10 dogs
```

**输出**
```
3
```

**说明**：数字分散在句子中，共有 `2`、`1`、`0` 三个数字字符。

---
