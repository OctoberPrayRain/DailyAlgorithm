# P03 - 递归求阶乘 测试用例

## 测试用例 1：0 的阶乘

**输入**
```
0
```

**输出**
```
1
```

**说明**：`0! = 1`，阶乘的基本边界条件。

---

## 测试用例 2：1 的阶乘

**输入**
```
1
```

**输出**
```
1
```

**说明**：`1! = 1`，递归的最小正整数用例。

---

## 测试用例 3：常规输入

**输入**
```
5
```

**输出**
```
120
```

**说明**：`5! = 5 × 4 × 3 × 2 × 1 = 120`。

---

## 测试用例 4：较大输入

**输入**
```
10
```

**输出**
```
3628800
```

**说明**：`10! = 3628800`，验证递归在较深层次下的正确性。

---

## 测试用例 5：最大合法输入

**输入**
```
20
```

**输出**
```
2432902008176640000
```

**说明**：`20!` 是 `unsigned long long` 能表示的最大阶乘值，测试上界。
