# P04 - 数组最值差 测试用例

## 测试用例 1：基础用例

**输入**
```
5
1 2 3 4 5
```

**输出**
```
4
```

**说明**：最大值 5，最小值 1，差为 `5 - 1 = 4`。

---

## 测试用例 2：包含负数

**输入**
```
4
-3 -1 2 7
```

**输出**
```
10
```

**说明**：最大值 7，最小值 -3，差为 `7 - (-3) = 10`。

---

## 测试用例 3：所有元素相同

**输入**
```
3
5 5 5
```

**输出**
```
0
```

**说明**：所有元素值相同，最值差为 0。

---

## 测试用例 4：仅一个元素

**输入**
```
1
42
```

**输出**
```
0
```

**说明**：只有一个元素时，最大值和最小值相同，差为 0。

---

## 测试用例 5：大范围数值

**输入**
```
3
-1000000000 0 1000000000
```

**输出**
```
2000000000
```

**说明**：测试较大范围的数值，验证是否使用了 `long long` 类型来避免溢出。
