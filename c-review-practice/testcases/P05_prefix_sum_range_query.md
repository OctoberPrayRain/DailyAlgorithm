# P05 - 区间和查询（前缀和） 测试用例

## 测试用例 1：基础单次查询

**输入**
```
5 1
1 2 3 4 5
0 4
```

**输出**
```
15
```

**说明**：查询整个数组 `a[0..4]` 的和，`1+2+3+4+5 = 15`。

---

## 测试用例 2：多次查询

**输入**
```
5 3
1 2 3 4 5
0 0
1 3
2 4
```

**输出**
```
1
9
12
```

**说明**：三次查询分别求 `a[0..0]=1`、`a[1..3]=2+3+4=9`、`a[2..4]=3+4+5=12`。

---

## 测试用例 3：包含负数

**输入**
```
4 2
-1 2 -3 4
0 3
1 2
```

**输出**
```
2
-1
```

**说明**：`a[0..3] = -1+2+(-3)+4 = 2`，`a[1..2] = 2+(-3) = -1`。

---

## 测试用例 4：单元素查询

**输入**
```
3 3
10 20 30
0 0
1 1
2 2
```

**输出**
```
10
20
30
```

**说明**：每次查询单个元素（`l == r`），结果即为该元素本身。

---

## 测试用例 5：全零数组

**输入**
```
5 2
0 0 0 0 0
0 4
2 3
```

**输出**
```
0
0
```

**说明**：数组元素全为零，任意区间和均为 0。
