# P06 - 统计元音 测试用例

## 测试用例 1：基础英文句子

**输入**
```
Hello World
```

**输出**
```
3
```

**说明**：元音字母为 `e`、`o`、`o`，共 3 个。

---

## 测试用例 2：全元音字符串

**输入**
```
aeiouAEIOU
```

**输出**
```
10
```

**说明**：所有字符都是元音（大小写各 5 个），共 10 个。

---

## 测试用例 3：无元音

**输入**
```
bcdfg hklmn
```

**输出**
```
0
```

**说明**：字符串中不包含任何元音字母。

---

## 测试用例 4：大小写混合

**输入**
```
Programming Is Fun
```

**输出**
```
5
```

**说明**：逐个检查 `P-r-o-g-r-a-m-m-i-n-g- -I-s- -F-u-n`，元音为 `o`、`a`、`i`、`I`、`u`，共 5 个。

---

## 测试用例 5：包含数字和特殊字符

**输入**
```
Test123!@#aEi
```

**输出**
```
4
```

**说明**：元音为 `e`（Test 中）、`a`、`E`、`i`，共 4 个。数字和特殊字符不计入。
