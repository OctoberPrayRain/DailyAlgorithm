# P07 - 原地反转字符串 测试用例

## 测试用例 1：基础字符串

**输入**
```
hello
```

**输出**
```
olleh
```

**说明**：将 `hello` 反转为 `olleh`。

---

## 测试用例 2：回文字符串

**输入**
```
abcba
```

**输出**
```
abcba
```

**说明**：回文字符串反转后与原字符串相同。

---

## 测试用例 3：包含空格的句子

**输入**
```
Hello World
```

**输出**
```
dlroW olleH
```

**说明**：整个字符串（包括空格）按字符反转。

---

## 测试用例 4：单个字符

**输入**
```
A
```

**输出**
```
A
```

**说明**：单字符反转后仍为自身。

---

## 测试用例 5：包含数字和符号

**输入**
```
abc123!@#
```

**输出**
```
#@!321cba
```

**说明**：所有字符（包括数字和特殊符号）都参与反转。
