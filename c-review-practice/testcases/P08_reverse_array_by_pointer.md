# P08 - 指针反转数组 测试用例

## 测试用例 1：基础用例

**输入**
```
5
1 2 3 4 5
```

**输出**
```
5 4 3 2 1
```

**说明**：5 个元素的数组反转。

---

## 测试用例 2：偶数个元素

**输入**
```
4
10 20 30 40
```

**输出**
```
40 30 20 10
```

**说明**：偶数长度数组的反转，无中间元素。

---

## 测试用例 3：单个元素

**输入**
```
1
42
```

**输出**
```
42
```

**说明**：只有一个元素，反转后仍为自身。

---

## 测试用例 4：包含负数

**输入**
```
6
-3 0 5 -7 2 8
```

**输出**
```
8 2 -7 5 0 -3
```

**说明**：包含正数、负数和零的数组反转。

---

## 测试用例 5：两个元素

**输入**
```
2
100 200
```

**输出**
```
200 100
```

**说明**：最小的需要交换的情况，两元素互换位置。
