# P09 - 结构体排序 测试用例

## 测试用例 1：基础排序

**输入**
```
3
Alice 90
Bob 85
Charlie 95
```

**输出**
```
Charlie 95
Alice 90
Bob 85
```

**说明**：按分数从高到低排序。

---

## 测试用例 2：分数相同按姓名排序

**输入**
```
4
Charlie 90
Alice 90
Bob 85
David 90
```

**输出**
```
Alice 90
Charlie 90
David 90
Bob 85
```

**说明**：Alice、Charlie、David 分数相同，按姓名字典序升序排列；Bob 分数最低排在最后。

---

## 测试用例 3：单个学生

**输入**
```
1
Zoe 100
```

**输出**
```
Zoe 100
```

**说明**：只有一个学生时无需排序，直接输出。

---

## 测试用例 4：已排序输入

**输入**
```
3
Alice 100
Bob 90
Charlie 80
```

**输出**
```
Alice 100
Bob 90
Charlie 80
```

**说明**：输入已按要求排好序，输出不变。

---

## 测试用例 5：全部同分

**输入**
```
5
Eve 75
Alice 75
Charlie 75
Bob 75
David 75
```

**输出**
```
Alice 75
Bob 75
Charlie 75
David 75
Eve 75
```

**说明**：所有学生分数相同，完全按姓名字典序升序输出。
