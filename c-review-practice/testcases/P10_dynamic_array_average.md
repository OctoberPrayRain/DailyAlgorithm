# P10 - 动态内存与平均值 测试用例

## 测试用例 1：基础用例

**输入**
```
4
1 2 3 4
```

**输出**
```
2.50
```

**说明**：`(1+2+3+4) / 4 = 2.50`。

---

## 测试用例 2：单个元素

**输入**
```
1
7
```

**输出**
```
7.00
```

**说明**：只有一个元素，平均值即为该元素本身。

---

## 测试用例 3：包含负数

**输入**
```
3
-6 0 9
```

**输出**
```
1.00
```

**说明**：`(-6+0+9) / 3 = 1.00`。

---

## 测试用例 4：结果需要小数

**输入**
```
3
1 2 4
```

**输出**
```
2.33
```

**说明**：`(1+2+4) / 3 = 2.333...`，保留两位小数输出 `2.33`。

---

## 测试用例 5：全零数组

**输入**
```
5
0 0 0 0 0
```

**输出**
```
0.00
```

**说明**：所有元素为零，平均值为 `0.00`。
