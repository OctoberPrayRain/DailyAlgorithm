# P11 - 统计二进制1的个数 测试用例

## 测试用例 1：基础用例

**输入**
```
5
```

**输出**
```
2
```

**说明**：`5` 的二进制为 `101`，包含 2 个 `1`。

---

## 测试用例 2：零

**输入**
```
0
```

**输出**
```
0
```

**说明**：`0` 的二进制为 `0`，不包含任何 `1`。

---

## 测试用例 3：2 的幂

**输入**
```
16
```

**输出**
```
1
```

**说明**：`16` 的二进制为 `10000`，只包含 1 个 `1`。2 的幂次方数都只有一个 `1`。

---

## 测试用例 4：全 1（8 位）

**输入**
```
255
```

**输出**
```
8
```

**说明**：`255` 的二进制为 `11111111`，包含 8 个 `1`。

---

## 测试用例 5：较大数值

**输入**
```
4294967295
```

**输出**
```
32
```

**说明**：`4294967295 = 2^32 - 1`，即 `unsigned int` 的最大值，32 位全为 `1`。
