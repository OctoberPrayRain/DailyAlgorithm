# P12 - 长度为k的子串最大元音数（滑动窗口） 测试用例

## 测试用例 1：基础用例

**输入**
```
abciiidef
3
```

**输出**
```
3
```

**说明**：长度为 3 的子串 `iii` 包含 3 个元音，为最大值。

---

## 测试用例 2：元音分散

**输入**
```
aeiou
2
```

**输出**
```
2
```

**说明**：每个长度为 2 的子串都恰好包含 2 个元音（`ae`、`ei`、`io`、`ou`），最大为 2。

---

## 测试用例 3：无元音

**输入**
```
bcdfgh
3
```

**输出**
```
0
```

**说明**：字符串中不包含任何元音字母，任意子串的元音数均为 0。

---

## 测试用例 4：k 等于字符串长度

**输入**
```
leetcode
8
```

**输出**
```
3
```

**说明**：`k` 等于字符串长度时只有一个子串，即整个字符串 `leetcode`，元音为 `e`、`e`、`o`，共 3 个。

---

## 测试用例 5：窗口滑动取最大值

**输入**
```
weallloveyou
5
```

**输出**
```
3
```

**说明**：滑动窗口依次检查长度为 5 的子串。如 `oveyo` 包含 `o, e, o`（3 个元音），`veyou` 包含 `e, o, u`（3 个元音），最大值为 3。
